# TaskTrackerAlpha
## 🚀 Локальная установка и запуск

### 1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/housesaroma/TaskTrackerAlpha.git
   cd ваш-репозиторий
  ```

### 2. Установите зависимости:

```bash
npm install
```
или
```bash
yarn install
```
или
```bash
pnpm install
```
### 3. Запустите проект в режиме разработки:

```bash
npm run dev
```
или
```bash
yarn dev
```
или
```bash
pnpm dev
```
После этого откройте http://localhost:5173 в браузере.
